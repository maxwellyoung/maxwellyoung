# Maxwell Young

I'm a design engineer at Silk. I work on web and mobile apps, mostly with React Native and Next.js.

A few things I've built:

- [SkillScan](https://github.com/maxwellyoung/skillscan): security checks for agent tools, npm packages, and VS Code extensions. One engine powers the [web scanner](https://skillscan.ninetynine.digital), [npm CLI](https://www.npmjs.com/package/@maxwellyoung/skillscan), and GitHub Action, with source-linked findings and SARIF reports.
- [T3 Craft](https://github.com/maxwellyoung/t3craft): a [released Minecraft mod](https://github.com/maxwellyoung/t3craft/releases/tag/v0.5.0) for managing coding agents across machines, answering approvals, and reviewing checkpoint diffs without leaving the game.
- [Liner](https://liner.ninetynine.digital): a music workspace with a custom canvas, playable audio, and local saving. Arrange demos, notes, references, and tracklists in one place.
- [doomscroll](https://github.com/maxwellyoung/doomscroll): an [iPhone app](https://apps.apple.com/nz/app/doomscroll-learn-code/id6759310735) for reviewing a codebase through swipeable cards, GitHub imports, and progress tracking.
- [music_maxwell](https://github.com/maxwellyoung/music_maxwell): my [music archive](https://www.maxwellyoung.info), with a typed release catalogue, artwork, lyrics, credits, and playable excerpts.

I also contribute to [T3 Code](https://github.com/pingdotgg/t3code/pulls?q=is%3Apr+is%3Amerged+author%3Amaxwellyoung) and take on occasional work through ninetynine digital.
